# wakariyasui-game

ゲームのスクリーンショットや動画をAIに見せて、ゲーム内容を理解できるかテストし、「分かりやすさ」を採点するプラグインです。

## コンセプト

AIが初見でゲームを理解できる = 人間にとっても分かりやすいゲーム、という前提に基づいています。

## 使い方

```
/wakariyasui-game
```

## 評価の流れ

1. **素材収集** (`game-material-collector`): スクリーンショットや動画を収集。素材がなければMCP経由でゲームをプレイして撮影
2. **テスト** (`game-tester`): 仕様を知らない状態で、素材だけを見てゲームの内容を説明
3. **採点** (`game-scorer`): 仕様書と照合し、テスターの説明の正確さを5段階で採点

## 採点項目

| 項目 | 内容 |
|------|------|
| ゲーム概要の理解 | ジャンルや世界観を正しく把握できたか |
| 目的の理解 | 勝利条件やクリア条件を理解できたか |
| 操作方法の理解 | 操作方法やUIの意味を読み取れたか |
| ルールの理解 | ルールやメカニクスを把握できたか |
| ゲームの流れの理解 | 進行の仕組みを把握できたか |
