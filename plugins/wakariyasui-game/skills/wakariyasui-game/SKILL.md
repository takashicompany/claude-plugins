ゲームの「分かりやすさ」を評価するスキルです。以下の手順で実行してください。

## 公正性に関する厳守事項

試験素材を当スキルで用意する際は、点数を稼ぐために作為的な素材の用意は禁ずる。あくまで、無作為に用意した素材で試験しゲームを正しく評価することが目的である。意図的な点数向上は最終的に製品の信頼の失墜を招く。公正な準備と判定と採点を強く命じる。

## 事前準備: 出力フォルダの作成

実行環境のカレントディレクトリに以下の構造で出力フォルダを作成してください。

```
wakariyasui-game-results/<ゲーム名>/
├── materials/          # 収集した素材（スクリーンショットや動画）
├── tester-report.md    # テスターの説明
├── scorer-report.md    # 採点結果
└── summary.md          # 全体のサマリー
```

## 手順

### Step 1: 素材の収集

評価対象のゲームのスクリーンショットや動画を収集してください。

- ユーザーが素材のパスを指定した場合はそこから収集する
- 素材がない場合はユーザーに素材の提供を依頼する

収集した素材は `materials/` フォルダにコピーまたは保存してください。
スクリーンショットのファイル名は連番のみにする（例: `001.png`, `002.png`, `003.png`）。

### Step 2: テスターによるゲーム説明

game-tester エージェントに、Step 1 で収集した素材のパスのみを渡してください。

**重要**: テスターにはゲームの仕様書、ソースコード、ストア説明文などの情報を一切渡さないでください。テスターは素材だけを見てゲームの内容を説明します。

テスターの説明を `tester-report.md` に保存してください。

### Step 3: 採点

game-scorer エージェントに以下の2つを渡してください:

1. Step 2 でテスターが作成した説明
2. ゲームの公式仕様（仕様書、ソースコード、ストア説明文など。ユーザーに場所を確認してください）

スコアラーはテスターの説明と公式仕様を比較し、ゲームの分かりやすさを採点します。

採点結果を `scorer-report.md` に保存してください。

### Step 4: サマリー作成と結果の報告

以下の内容を `summary.md` に保存してください:
- 評価対象のゲーム名
- 実行日時
- 使用した素材の一覧
- 参照した仕様情報の概要
- 総合スコアと各項目のスコア

サマリーをユーザーに報告してください。
