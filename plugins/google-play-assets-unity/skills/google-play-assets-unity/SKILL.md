# Google Play Assets Generator

Google Play公開に必要な画像素材を自動生成するスキルです。

## 前提条件

- Unity Editorを操作できるMCPサーバーが接続されていること（playmode制御、screenshot撮影、ゲーム操作、GameView解像度設定が可能なもの）
- MCPが利用できない場合はその旨を伝えて終了すること

## 実行手順

### Step 1: 環境確認

1. MCP経由でUnity Editorの状態を取得し、MCPが利用可能であることを確認する
2. 利用できない場合は「Unity Editorを操作できるMCPサーバーが必要です」と伝えて終了する

### Step 2: ゲームの理解

1. プロジェクトのコードベース（シーン構造、スクリプト、プレハブ等）を読み、以下を把握する：
   - どういうジャンル・ルールのゲームか
   - どう操作するか
   - 画面遷移はどうなっているか（タイトル、ゲームプレイ、リザルト等）
   - ステージやレベルの切り替え方法はあるか
   - どういう画面状態のバリエーションが存在するか
2. 把握した内容をユーザーに報告し、認識が合っているか確認する

### Step 3: GameView解像度の設定

MCPでGameViewの解像度をストア用スクリーンショットの要件に設定する。

- **スマホ縦向き**: 1080 x 1920（9:16）
- **スマホ横向き**: 1920 x 1080（16:9）

ゲームの向きに応じて適切な方を選択する。判断できない場合はユーザーに確認する。

### Step 4: スクリーンショット撮影

1. MCPでPlayモードを開始する
2. Step 2で理解したゲームの仕組みに基づいて、MCPで利用可能な操作を使ってゲームを操作する
   - 様々な画面状態・場面のバリエーションを作り出す
   - ステージ切替が可能なら複数ステージでSSを撮る
3. バリエーション豊かな場面ごとにスクリーンショットを撮影する
   - 保存先: `StoreAssets/GooglePlay/Screenshots/`
   - ファイル名: `gp_ss_001.png`, `gp_ss_002.png`, ...
   - 最低30枚撮影する
4. Playモードを停止する

### Step 5: トリミング候補の生成

撮影したスクリーンショットから、以下のトリミング候補をランダムに生成する。

#### アイコン候補（512 x 512 px）
- 各スクリーンショットからランダムな位置で512x512にクロップ
- 合計30枚生成
- 各スクリーンショットからなるべく均等に生成する
- 保存先: `StoreAssets/GooglePlay/Icons/`
- ファイル名: `gp_icon_001.png`, `gp_icon_002.png`, ...
- 形式: PNG（32-bit）

#### フィーチャーグラフィック候補（1024 x 500 px）
- 各スクリーンショットからランダムな位置で1024x500にクロップ
- 合計30枚生成
- 各スクリーンショットからなるべく均等に生成する
- 保存先: `StoreAssets/GooglePlay/FeatureGraphics/`
- ファイル名: `gp_fg_001.png`, `gp_fg_002.png`, ...
- 形式: PNG（24-bit、アルファなし）

### Step 6: 結果報告

生成した素材の一覧と保存場所をユーザーに報告する。

```
StoreAssets/GooglePlay/
├── Screenshots/        # ストア掲載用スクリーンショット（1080x1920 or 1920x1080）
│   ├── gp_ss_001.png
│   └── ... (30枚以上)
├── Icons/              # アイコン候補（512x512）x 30枚
│   ├── gp_icon_001.png
│   └── ...
└── FeatureGraphics/    # フィーチャーグラフィック候補（1024x500）x 30枚
    ├── gp_fg_001.png
    └── ...
```

## Google Playストア素材の仕様（参考）

| 素材 | サイズ | 形式 | 必要枚数 |
|------|--------|------|---------|
| ストア用アイコン | 512 x 512 | PNG (32-bit) | 1枚 |
| フィーチャーグラフィック | 1024 x 500 | JPEG/PNG (24-bit, アルファ不可) | 1枚 |
| スクリーンショット（スマホ） | 1080 x 1920 | JPEG/PNG | 最低2枚 |
