# booth-review

回答完了時に根拠チェックを強制するプラグインです。アメフトの「ブースレビュー」（審判ブースからの自動判定検証）に由来します。

## 仕組み

`Stop` フックに `type: "prompt"` を設定し、Claudeが回答を終えるたびにLLMが根拠チェックを実行します。

### チェック内容

1. 回答に含まれる事実の主張を列挙
2. 各主張に根拠（ソースコード参照 or URL付き一次情報）があるか判定
3. 根拠のない主張がある場合 → **block**（Claudeに差し戻し、根拠の補足または撤回を要求）
4. すべての主張に根拠がある場合 → **approve**（回答確定）

### チェック対象外

- コード生成のみの回答
- 挨拶、確認、質問など事実の主張を含まない回答

## 関連プラグイン

- **playbook**: プロンプト送信時にルールを注入するプラグイン。併用を推奨。
