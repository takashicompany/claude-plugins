# ゲーム側の「撮影モード」(組み込み時)

人が撮る場合、同じ面を何度も撮り直してよいテイクを選ぶことになる。
毎回操作して面を戻さなくて済むよう、`?rec` のときだけゲームの進み方を変える。
**ゲームの作りに依存するため共通ライブラリにはしていない**。以下を目安にゲーム側へ書き足す。

差し込み (AI が撮る) では基本的に不要。Playwright は毎回まっさらなブラウザで開くので進み具合は汚れず、
面の指定やクリア後の扱いは台本で制御できる。

## 入れるもの

| 項目 | 通常プレイ | 撮影モード |
|---|---|---|
| レベル指定 | 保存された続きから | `?level=N` があればその面から (保存値より優先) |
| クリア後 | 次の面へ進む | クリア演出を 1〜1.5 秒見せて、**同じ面を最初から** |
| 失敗後 | ゲームオーバー画面 | 失敗の演出は見せ、画面は出さずに同じ面を最初から |
| 進み具合の保存 | 保存する | **保存しない** |

判定は録画ライブラリと同じ条件にそろえる。

```js
const REC_MODE = /[?&]rec=(1|true)(&|$)/.test(location.search);
```

## 作り方の要点

- **判定はゲームの初期化より前に行う**。起動直後に最初の面を保存するゲームは、後から止めても遅い
- **保存の入口を 1 か所で止める**。`saveProgress()` のような関数の先頭で `if (REC_MODE) return;`
  (録画サイズの選択など、進み具合以外の保存は止めなくてよい)
- **面のやり直しは通常のリセット処理を呼ぶ**。撮影モード専用の後始末を増やすと、音や演出の止め忘れが起きる
- **演出は削らず、画面だけ出さない**。失敗の演出は動画の見せ場になる
- クリア後に自動で戻る処理は、手動リセットや面の変更で取り消せるようにする (タイマーの二重起動を防ぐ)
- 画面上のレベル名などを隠したい場合、DOM なら `hideSelectors` で済む。canvas に描いているなら描画側で分岐する
- 撮影中にキー操作などで面を変えられるかどうかは、ゲームごとに決めて書いておく

## 確認

1. `?rec` なしで従来どおり遊べる (クリアで次へ、保存される)
2. `?rec=1&level=N` で N 面から始まる
3. クリア → 演出後に同じ面の最初へ戻る。面番号は変わらない
4. 失敗 → ゲームオーバー画面が一度も出ずに最初へ戻る (40ms 間隔などで状態を見張る。単発の確認では見逃す)
5. 撮影モードで遊ぶ前後で、localStorage の進み具合のキーが変わらない
