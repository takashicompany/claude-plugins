# game-planner

ゲームの曖昧なアイデアから、対話を通じて仕様書 (`plan.md`) を作るスキル。

## 何ができるか

「砂を試験管に並べ替えるゲーム」のような一言のアイデアから、実装担当が読んで迷わず作れるレベルの仕様書まで、AI が質問と調査を組み合わせて引き出す。

ユーザーは AI が出す選択肢を選んでいくだけで仕様が固まっていく。

## 使い方

```
/game-planner:game-planner
```

または「ゲームの企画を考えたい」「アイデアを仕様書にしたい」と話しかければ自動で起動する。

## フロー

1. **最初の2問** （固定）
   - 一言で説明するとどんなゲーム？
   - 参考ゲーム/類似ゲームは？
2. **調査** — `game-researcher` サブエージェントが参考ゲーム / 類似ジャンルを Web で調査。AppMagic MCP が使える環境ならそれも併用、無くても WebSearch のみで完走する。
3. **対話ループ（型なし）** — AI がそのアイデアに応じて「質問する / 追加調査する / 押し戻す / 書き出す」を毎ターン判定して進める。質問は AskUserQuestion で必ず選択肢を提示する。
4. **仕様書の書き出し** — Definition of Done を満たした時点で `plan.md` を書く。
5. **批評ループ** — AI が粗探し役で読み返し、抜けや矛盾があれば追加質問してアップデート。

## 設計方針

- **固定の質問テンプレートを持たない**（フォーム埋めに堕ちないため）
- **質問は AskUserQuestion で必ず選択肢を提示**（ユーザーは選ぶだけ）
- **「広 → 狭」「曖昧 → 具体」** の方向性だけ AI に指針として渡す
- **AppMagic MCP に依存しない**（無くても完走する）
